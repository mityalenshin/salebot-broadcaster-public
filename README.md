# SaleBot Broadcaster

Своя система массовых рассылок поверх SaleBot — с обходом квоты тарифа,
веб-дашбордом аналитики, отложенными рассылками и автоматическим обновлением базы.

## 🚀 Быстрый старт (для учеников)

Если хочешь развернуть систему у себя — есть автоматический путь:

1. Прочитай **[docs/QUICKSTART.md](docs/QUICKSTART.md)** — что собрать (VPS, домен, токены)
2. Открой **[docs/CLAUDE_PROMPT.md](docs/CLAUDE_PROMPT.md)** — копируй промпт, заполни своими данными, отправь Claude Code
3. Claude развернёт всё за 15-20 минут, включая миграцию

`setup.sh` в корне — автоматический инсталлятор для чистого Ubuntu (Claude его сам запустит).

## Идея

SaleBot оставляем для воронок (приём `/start`, ведение клиента по сценарию).
А рассылку шлём **напрямую через Telegram Bot API** с тем же токеном бота —
SaleBot про это не знает и квоту не списывает.

Экономия — десятки тысяч рублей в месяц при базе 50 000+ клиентов.

## Что умеет

### Рассылки
- Пошаговый визард создания (`/new`): текст / фото с подписью / inline-кнопки
- Персонализация — плейсхолдеры `{{name}}` и `{{first_name}}` подставляются
  индивидуально для каждого получателя
- Multi-tag фильтрация — рассылка по нескольким сегментам одновременно
- UTM-метки — автоматически добавляются в URL кнопок для аналитики в Я.Метрике/GA
- Растяжка во времени — равномерное распределение рассылки на 30 мин / 1ч / 2ч / 4ч
  (менее «бот-подозрительно»)
- Отложенные рассылки — `/scheduled`, scheduler-поток запускает в указанное время
- Двойное подтверждение для рассылок > 5 000 (защита от случайного клика)
- Live-прогресс отправки в чате с обновлением каждые 300 сообщений
- Lock-файл от запуска двух рассылок одновременно
- Уважение `Retry-After` от Telegram (rate-limit 25 req/sec)
- На лету помечаем заблокировавших → исключаются из следующих рассылок

### База клиентов
- Один раз — миграция всех клиентов из SaleBot API в локальную SQLite
- Webhook от SaleBot — новые лиды попадают в базу за секунды после активации воронки
- `check_alive` через `sendChatAction` — невидимая проверка, заблокирован ли бот
- Ежедневная авто-проверка активности новых клиентов (cron в 04:00 МСК)

### Аналитика
- Веб-дашборд `/dashboard` (защищён токеном) — Tailwind + Chart.js
- Карточки KPI: всего / active / blocked / not_started
- Гистограмма рассылок за 30 дней
- Таблица последних 30 рассылок со статусами
- Топ-10 ботов и тегов

### Production-готовность
- Деплой на VPS под Ubuntu 24.04 / Python 3.12
- systemd-сервисы для бота и webhook (автозапуск, авто-рестарт)
- Ежедневный бэкап SQLite в `/root/_backup/` с ротацией 14 дней
- nginx + Let's Encrypt SSL

## Состав

| Файл | Что |
|------|-----|
| `db.py` | SQLite, миграции схемы, UPSERT клиента |
| `migrate.py` | Выгрузка клиентов из SaleBot API → SQLite (пагинация по 500) |
| `check_alive.py` | Проверка живости через `sendChatAction` (тихо, не палится) |
| `audience.py` | Выборка получателей с фильтрами (bot_group, tag, tags) |
| `broadcast.py` | Движок рассылки: rate-limit, retry на 429, персонализация, UTM, растяжка |
| `post_builder.py` | Парсинг `[текст \| url]` кнопок, перезаливка фото между ботами |
| `wizard.py` | FSM-визард создания рассылки + scheduler-helpers |
| `bot.py` | Бот команд (pyTelegramBotAPI), команды управления, scheduler-thread |
| `webhook.py` | Flask + waitress: приём webhook от SaleBot, регистрирует dashboard |
| `dashboard.py` | Blueprint с защищённой страницей и API-эндпоинтами |
| `templates/dashboard.html` | HTML-страница дашборда (Tailwind + Chart.js через CDN) |
| `poc_send.py` | Однократный proof-of-concept: отправка идёт мимо квоты SaleBot |
| `deploy/` | systemd units, cron-задачи, nginx-template, deploy.sh |

## Запуск

```bash
# первоначально
cp .env.example .env
# отредактировать .env: вписать токены, ключи

python3.12 -m venv venv
./venv/bin/pip install -r requirements.txt

# выгрузить клиентов
./venv/bin/python migrate.py

# проверить активность
./venv/bin/python check_alive.py

# запустить бот команд (long polling)
./venv/bin/python bot.py
```

## Команды бота команд

```
/new                — пошаговое создание рассылки (визард)
/scheduled          — список запланированных
/cancel_scheduled X — отменить запланированную #X
/cancel             — прервать создание рассылки в визарде
/stats              — сводка по базе
/segments           — доступные сегменты (теги, боты)
/preview            — превью на тестовых (реплаем)
/send               — массовая рассылка (реплаем). Опц: tag=X / tags=a,b,c / bot=Y
/status             — прогресс активной рассылки (% готово, ETA, скорость)
/history            — последние 10 рассылок со статусами
/broadcast X        — детали по рассылке #X
/cancel_lock        — снять lock-файл (только если процесс упал)
/help               — справка
```

## Визард создания рассылки

```
/new
  → пришли сообщение (текст / фото с подписью / с кнопками)
  → выбери бота (radio button)
  → выбери теги (можно несколько — toggle, или ничего = всем активным)
  → когда отправить (🚀 сейчас / ⏰ запланировать → ввод времени)
  → опции (☑ UTM-метки, ◯ растяжка 0/30м/1ч/2ч/4ч)
  → подтверждение
  → если получателей > 5 000 — ввод "ОТПРАВИТЬ" заглавными
```

Кнопки добавляются в конце текста строкой `[Текст | https://url]`.
Плейсхолдеры в тексте: `{{name}}`, `{{first_name}}`.
