# 🚀 QUICKSTART для учеников

Эта инструкция — для тех, кто хочет развернуть **свою собственную** копию SaleBot Broadcaster
на своём VPS-сервере. Установку дальше сделает Claude Code (см. [CLAUDE_PROMPT.md](CLAUDE_PROMPT.md)).

Эта страница — что собрать руками **до того**, как передавать управление Claude.

---

## Что в итоге получится

- Свой бот команд в Telegram, через который ты управляешь рассылками
- Свой webhook от SaleBot, который автоматически обновляет твою базу
- Свой веб-дашборд аналитики с графиками
- Рассылки идут **в обход квоты SaleBot** (через прямой Telegram Bot API)

---

## Что нужно подготовить

### 1. VPS (виртуальный сервер)

**Где взять:** Timeweb, Beget, Reg.ru, Hetzner, любой провайдер.

**Минимальная конфигурация:**
- ОС: **Ubuntu 22.04 или 24.04**
- 2 vCPU, 2 GB RAM, 30 GB SSD — **достаточно для 50k клиентов**
- Цена: ~500-1000 ₽/мес

**Что иметь после покупки:**
- IP-адрес сервера
- Логин (обычно `root`)
- SSH-доступ:
  - Либо пароль (на первое время сойдёт)
  - Либо публичный ключ — лучше, безопаснее. Если умеешь — сделай через [ssh-keygen](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent)

### 2. Домен (или поддомен)

**Где взять:** reg.ru, beget, namecheap. Стоит ~200₽/год.

**Что нужно сделать:**
- Купить любой домен, например `myname.ru`
- В DNS-настройках добавить **A-запись** на IP твоего VPS:
  ```
  Тип: A    Имя: salebot    Значение: 203.0.113.10    TTL: 3600
  ```
  Получится поддомен `salebot.myname.ru` → твой VPS.
- Подождать 5-15 минут, пока DNS обновится.
- Проверить: `dig +short salebot.myname.ru` должен вернуть IP сервера.

### 3. Два Telegram-бота

Открой в Telegram **@BotFather** и создай **два бота**:

**Бот №1 — для рассылок** (от его имени будут уходить сообщения подписчикам)
- Если у тебя уже есть бот в SaleBot — используй его, не создавай новый
- Если нет — `/newbot` → имя → username (обязательно заканчивается на `_bot`)
- Сохрани **токен** (длинная строка вида `123456:ABC-DEF...`)
- Сохрани **username** (без @)

**Бот №2 — для команд** (через него ты будешь управлять рассылками)
- `/newbot` → имя «Мой админ-бот» → username `myname_admin_bot`
- Сохрани **токен** и **username**

### 4. API-ключ SaleBot

- Войди в SaleBot, открой свой проект
- Настройки → Интеграции → API-ключ → создай новый ключ с правами:
  - ✅ Чтение клиентов
  - ✅ Изменение/удаление информации о клиентах
- Скопируй и сохрани ключ.

### 5. Группа для управления и тестов

В Telegram создай группу типа «Работа с рассылками» (или используй существующую):
- Добавь туда бота команд (№2)
- Сделай его администратором (или хотя бы дай разрешение читать сообщения)
- Напиши в группе любое сообщение **с упоминанием бота**: `@myname_admin_bot привет`
- Зайди в браузере: `https://api.telegram.org/bot<ТОКЕН_БОТА_2>/getUpdates`
- Найди в JSON `chat.id` группы — это число, обычно отрицательное (`-100123456789`)

Также узнай **свой личный chat_id**:
- В Telegram открой @userinfobot, отправь любое сообщение, он пришлёт твой `id`.
- Или отправь `/start` своему боту команд, потом смотри `getUpdates`.

### 6. Email для SSL-сертификата

Любой рабочий email. Будет использоваться при выпуске SSL через Let's Encrypt.

## Сводка — что должно быть на руках

| Что | Пример | Где взять |
|-----|--------|-----------|
| IP VPS | `203.0.113.10` | у хостинга |
| SSH доступ | пароль или ключ | у хостинга |
| Домен/поддомен | `salebot.myname.ru` | reg.ru → DNS A-запись |
| Email | `me@gmail.com` | свой |
| Бот рассылок | токен + username | @BotFather |
| Бот команд | токен + username | @BotFather |
| SaleBot API-ключ | hex-строка | SaleBot → Настройки → API |
| Твой Telegram username | `your_username` (без @) | свой |
| Твой chat_id | `123456789` | @userinfobot |
| Chat_id рабочей группы | `-100123456789` | getUpdates после упоминания бота в группе |

## Что дальше

Когда всё это собрано — открывай файл [CLAUDE_PROMPT.md](CLAUDE_PROMPT.md), копируй промпт оттуда,
вставляй свои данные и передавай Claude Code. Дальше он развернёт всё сам за 15-20 минут.

**Важно:** все собранные данные (токены, пароли) считаются **секретными** —
не публикуй их нигде, не шли в обычные чаты, не коммить в git.
Передавать их можно только Claude Code в своей сессии.
